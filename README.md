# StudyNaija

StudyNaija is an educational platform for Nigerian students.

## Features

- Student registration
- Student login
- Student dashboard
- Lesson notes
- Practice questions
- Points system
- Leaderboard
- AI Tutor
- Admin dashboard
- PostgreSQL support
- SQLite support for local development
- Responsive mobile design
